Les quatre prévisualisations Vercel sont READY. Les routes publiques `/connexion` et `/inscription/professeur` répondent 200 sur le domaine de production. Les branches de recette locales combinent certains lots pour les tests ; aucune fusion de ces lots n’a été demandée à GitHub à ce stade.

**Courrier.** Le connecteur Supabase montre un projet et aucune branche de développement. Vercel identifie SUPABASE_URL comme sensible et ne renvoie pas sa valeur. Le compte Resend accessible vérifie le domaine nireo.fr ; des enregistrements SPF (send), DKIM (resend) et DMARC ont été trouvés pour ce domaine. Cela ne confirme ni l’adresse expéditrice effectivement saisie dans Supabase ni la livraison du code AvecStudy. La recherche du contexte inscription_professeur sur 50 minutes de logs Vercel n’a pas donné d’événement. Un avertissement de protection des mots de passe compromis existe sur le projet Supabase visible. Vérifier la référence de production avant toute décision de configuration.

**Pour reprendre.** Confirmer le projet dans les paramètres de production, puis renseigner hors Git le projet Supabase séparé et la boîte contrôlée. Relever heure UTC, code d’erreur Auth, événement fournisseur, réception et validation de session sur une même tentative. Ne changer SMTP ou les DNS qu’après avoir identifié l’étape en défaut. Rejouer les parcours navigateur sur la révision candidate et sur un environnement stable : les essais Windows en développement ont aussi rencontré des expirations de délai pendant la compilation.
