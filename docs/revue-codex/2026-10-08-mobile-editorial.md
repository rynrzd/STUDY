# Landing mobile — direction éditoriale 01

Version demandée et publication directe autorisée par l'utilisateur. Base : main 608e95d. Les modifications de présentation s'appliquent sous 768 px. Le contenu alternatif est masqué avec display:none ; un seul H1 reste dans le document.

- Accroche « Le cours se termine. L’apprentissage continue. », message de marque et action principale pleine largeur.
- Aperçu mobile indépendant du grand panneau bureau : cours, travail à faire, illustration de cahier en CSS/SVG et mention explicite de données illustratives.
- Le lien de l'aperçu ouvre la présentation des cours, jamais un faux compte élève.
- Menu existant et connexion conservés ; étapes professeur, échanges et pied de page adaptés au petit écran.
- Aucune bibliothèque ajoutée, aucune migration ni modification de l'authentification. Illustration codée, sans photo ni 3D.

Contrôles : build de production (incluant TypeScript) réussi ; lint et diff vérifiés avant publication. Pas de recette sur téléphone physique. Le navigateur distant ne pouvait pas atteindre la prévisualisation locale ; ne pas présenter ces contrôles comme une validation visuelle multi-appareils.
